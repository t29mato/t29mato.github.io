tmuxからくり屋敷

襖が立ち、部屋が回り、壁が外れて大広間になる。
指図どおりに襖を立て、間を渡り、棟を建て、巻物を読む。
奥の間に辿り着くまでの速さを競う。押すキーはいつも指図に書いてある。

隣の間へ
本物の tmux で同じにするには

プラグイン（vim-tmux-navigator）を TPM で入れる。vim の中でも同じキーで窓を渡れる。

# ~/.tmux.conf
set -g @plugin 'christoomey/vim-tmux-navigator'
run '~/.tmux/plugins/tpm/tpm'

" ~/.vimrc（vim-plug）
Plug 'christoomey/vim-tmux-navigator'

プラグインなしで tmux だけなら:

bind -n C-h select-pane -L
bind -n C-j select-pane -D
bind -n C-k select-pane -U
bind -n C-l select-pane -R
bind -n 'C-\' select-pane -l

はじめての人は三間屋敷へ。1 仕掛け 1 キーで、指図を見ながら解ける。記録はこのブラウザの中に残る。名前か合言葉を付けたときだけ、番付と端末の引き継ぎのために送る。

見取り図 ― 屋敷を選ぶ
