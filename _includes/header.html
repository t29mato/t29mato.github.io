{%- comment -%} Overrides minima's header.html. The header is the session's window list, tmux-style: every page in `header_pages` is a numbered window, home is window 0, and the current one carries the star. No hamburger — a window list that wraps is more terminal than a menu that hides. A post belongs to the blog window even though its URL is not /blog/, so the loop checks the collection as well as the URL. The theme toggle ships both glyphs in the markup and CSS decides which one shows, so it renders correctly on first paint with no JavaScript. {%- endcomment -%}
[mato-site]
0:home{% if page.url == "/" %}*{% endif %} {%- assign default_paths = site.pages | map: "path" -%} {%- assign page_paths = site.header_pages | default: default_paths -%} {%- for path in page_paths -%} {%- assign my_page = site.pages | where: "path", path | first -%} {%- if my_page.title -%} {%- assign is_current = false -%} {%- if page.url == my_page.url -%} {%- assign is_current = true -%} {%- elsif my_page.url == "/blog/" and page.collection == "posts" -%} {%- assign is_current = true -%} {%- endif -%} {{ forloop.index }}:{{ my_page.title | downcase | escape }}{% if is_current %}*{% endif %} {%- endif -%} {%- endfor -%}
