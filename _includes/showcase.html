Optional: note, source, tags, rating (1-5), source_label, action. A page-wide `action="Play"` sets the link text for every card at once. The markup lives here rather than in each page so the three lists cannot drift apart — the whole point of having one pane language. Each pane opens with the preview's own filename, derived from `img`, so the screenshot reads as an inline image preview and not a marketing thumbnail. {%- endcomment -%}
