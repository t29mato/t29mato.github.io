topology

the path a packet takes, left to right: workstation → the air → the uplink → the wired segment → the hosts. logical names only.

  • ━━■ copper, 1000BASE-T: a run that ends in a jack. □ jack waiting for a machine.
  • ))) the air, Wi-Fi: a field, never a line — nothing here takes a switch port.
  • ▮ ▯ sw-1 port: green = up, amber = reserved, hollow = spare. 6 of 8 used.
  • ╌╌ dashed box = planned: wiring in place, host not yet.
  • batt on the 288 Wh LiFePO4 station: gw-1, sw-1, pi-1 — deliberately not the minis.
  • → status leaves outward only; no host accepts a connection from outside the LAN.

Each host pushes its own heartbeat to a public endpoint, so the page that reports a failure is not inside the thing that failed. No addresses, names or SSIDs appear here on purpose.
